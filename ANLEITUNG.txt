ANLEITUNG: Daten auf der Webseite selbst ändern
===============================================

Sie brauchen keine Programmierkenntnisse.

Welche Datei?
  Die Datei "daten.txt". Hier stehen alle Daten, die sich jedes Jahr ändern
  (Saisonstart, Saisonende, Jahr, Sommerpause, Mittwochs-Zeiten).

Was ist mit Word?
  Eine Word-Datei kann eine Webseite leider nicht direkt lesen. Darum gibt es
  die einfache Textdatei "daten.txt". Sie funktioniert wie ein sehr einfaches
  Word: einfach Text ändern, speichern, fertig.

So ändern Sie ein Datum:
  1. Öffnen Sie "daten.txt" mit dem Editor (Windows) oder TextEdit (Mac).
     Ein Doppelklick genügt meistens.
  2. Ändern Sie nur den Text NACH dem Doppelpunkt.
     Beispiel:   saisonstart: 5. Oktober 2026
     wird zu:    saisonstart: 6. Oktober 2027
  3. Den Namen vor dem Doppelpunkt (z. B. "saisonstart") NICHT ändern.
  4. Speichern.
  5. Die Datei auf GitHub ersetzen:
       - GitHub öffnen und in das Projekt gehen
       - Auf "daten.txt" klicken, dann auf das Stift-Symbol (Bearbeiten)
       - Text ändern und unten auf "Commit changes" klicken
       (Oder: "Add file" > "Upload files" und die neue daten.txt hochladen.)
  6. Nach 1 bis 2 Minuten ist die Webseite aktualisiert.

Was die Webseite von selbst macht (Sie müssen nichts tun)
  - Vom 15. September bis 7. Mai steht der Winter (Ski, Vermietung, Service,
    Öffnungszeiten) zuerst. Danach stehen die Bodenbeläge zuerst.
  - Im Sommer verschwinden nur der Winter-Banner mit Saisonstart, der Skitest
    und die Winter-Öffnungszeiten. Stattdessen erscheint der Hinweis
    "Sommerpause" mit den Daten, wann das Sportgeschäft wieder öffnet.
    Vermietung (Preise) und Ski & Boardservice bleiben das ganze Jahr
    abrufbar, nur ohne grosse Bilder und weiter unten.
  - Die Jahreszahlen in den Daten (Saisonstart, Saisonende, "Winter 26/27")
    rücken jedes Jahr automatisch ein Jahr weiter. Es steht nie ein altes
    Datum auf der Seite. Tag und Monat bleiben, wie in daten.txt eingetragen.
  - Das Datum der Umschaltung stellen Sie bei "umschalten_ski" und
    "umschalten_boden" ein (Format Tag.Monat., zum Beispiel 15.9. oder 7.5.).
  Ändert sich einmal der Tag oder Monat (zum Beispiel neuer Saisonstart am
  12. Oktober), dann nur die Zeile in daten.txt anpassen.

Flyer, Bilder und PDF austauschen
  - Der Flyer ist ein Bild (Datei auf der Seite) und ein Link auf das PDF.
  - Neues PDF: Auf GitHub in das Projekt gehen, "Add file", "Upload files",
    das neue PDF hineinziehen und "Commit changes" klicken.
    Der Link zum Flyer bleibt gleich, wenn die Datei gleich heisst.
  - Bild austauschen: neue Datei mit genau demselben Dateinamen hochladen,
    sie ersetzt die alte.
  - Für alles andere (neue Texte, neue Bereiche) wenden Sie sich bitte an
    die Person, die Ihnen die Webseite geliefert hat.

Wichtig
  - Die Datei muss "daten.txt" heissen und neben "index.html" liegen.
  - Dies funktioniert, sobald die Webseite online ist (z. B. GitHub Pages).
    Beim Öffnen von index.html per Doppelklick auf dem Computer werden die
    Standardtexte angezeigt.
  - Wenn eine Zeile fehlt oder falsch ist, bleibt der bisherige Text stehen.
    Es geht also nichts kaputt.
